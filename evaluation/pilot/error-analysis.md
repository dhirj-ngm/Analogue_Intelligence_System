# Pilot error analysis

Read rankings.json in baselines/ alongside frozen judgements.jsonl. These judgements were authored by the same assistant who curated the corpus, before rankings. They are provisional, not independent ground truth.

- **Q1 material/packaging pressure:** both methods return five relevant candidates under the rubric. Dense places CL-2008 first; BM25 places CLX-2021 first. The former is a closer packaging narrative; the latter has extra shipment/absorption drivers. A comparison screen needs to expose those differences.
- **Q2 falling shipments and fixed-cost absorption:** KC-2011 has useful production-curtailment evidence, but BM25 places it fifth and dense second. Both rank CL-2015 first even though currency-driven costs and rising margin make it weak for this question. Dense improvement does not eliminate superficial matches.
- **Q3 currency-related input costs:** only CL-2008 and KC-2011 predate the target. Both rank the same way and achieve nDCG 1.0 under labels, yet neither establishes the requested currency mechanism. Grade 2 for CL-2008 means a partial input-cost comparison only. This high nDCG is a tiny-candidate/label limitation, not proof of a good answer. P@5 remains 0.2 because denominator 5 is fixed.
- **Q4 disruption/volume pressure:** BM25 retrieves three grade>=2 cases in its top five; dense retrieves two. BM25's first result CL-2020 is a weak demand-expansion contrast; dense's first CL-2022 provides little direct disruption evidence. Neither retrieves a historical cyberattack analogue, since the source cyber case is excluded. Similar volume vocabulary is insufficient.
- **Q5 embargo:** no case supports the requested mechanism, although both produce scores/ranks. All relevance grades are zero. Show insufficient evidence for this benchmark query. An automatic abstention rule is not implemented or validated; the free-text CLI explicitly warns that its candidates are uncalibrated.

No labels were changed after results. No structural features were tested. Annotation language may help retrieval artificially; correlated companies/periods and the small corpus limit inference. Ten observations do not establish ten independent episodes. Unknown rationale/follow-up is not a negative outcome or absence of action.

Actual execution issues: sandbox DNS prevented package/model access; approved network execution succeeded. Initial generic dependency resolution included large GPU packages, so the installer was stopped and CPU PyTorch installed. The hub transfer was slow and a direct weights fetch was attempted redundantly; the hub run eventually succeeded. Initial lint flagged a lambda assignment and was fixed. Byte-for-byte repeat comparison failed on floating-point scores; rank order and metrics matched, and score deviations passed the predeclared 1e-5 tolerance. No model/label tuning followed these findings.
